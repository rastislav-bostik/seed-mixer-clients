# ios-native (placeholder)

Future home of the **Swift + SwiftUI** iOS client.

Built **after** `flutter-app/` proves the data model and UX. Same screens, native iOS implementation — to feel the difference: previews, environment values, native gestures, Dynamic Type, system integrations (Share Sheet, Spotlight, Siri Shortcuts).

Planned stack:
- Swift 5.10+
- SwiftUI
- Observation framework (`@Observable`)
- `URLSession` (HTTP) + `Codable`
- `AsyncImage` + custom cache
- Optionally: SwiftData for local persistence

Status: not started — directory kept to mark intent.
